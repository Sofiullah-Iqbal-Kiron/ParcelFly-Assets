# Fonts

All fonts in this folder are licensed under the SIL Open Font License 1.1 (see each `OFL.txt`). They may be used for
commercial work, installed on any machine and bundled with software and websites.

| Family | Folder | Used for |
|---|---|---|
| Montserrat (variable 100 to 900) | `montserrat/` | English headlines, body and labels |
| Mina Regular and Bold | `mina/` | Bangla wordmark lockups, Bangla taglines and display |
| Noto Sans Bengali (variable) | `notosansbengali/` | Bangla body text and UI |
| Geist Mono (variable) | `geistmono/` | Tracking numbers, codes |

Sources: the official Google Fonts repository (github.com/google/fonts, `ofl/` folder).

## Not included: Nasalization

The Parcel Fly wordmark is Nasalization Rg by Typodermic Fonts. Its desktop licence allows logos as fixed artwork but
forbids sharing the font file, embedding it in apps or websites, editable templates, and storing it on shared servers.
The kit therefore contains only the outlined wordmark (`source/master/wordmark-en.svg`). Do not add the font file to
this folder or to any repository.
